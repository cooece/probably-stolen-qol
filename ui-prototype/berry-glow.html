为什么不用符号

V / | / + / ⊣ 四个形状和品质没有直觉关联。玩家要先学一张对照表， 再在背包里逐个辨认——等于把"看一眼"变成了"读一遍"。

为什么不用色块

果实本身就有颜色（紫 / 偏橙 / 偏紫红）。再叠红黄绿蓝，同一个图标上出现两套颜色语义， 反而更乱。光晕是"加强原有颜色"，不是"覆盖"。

光晕的信息在哪

就一个字：亮。亮到暗是连续的量，符合"品质"这种渐变概念； 而且它直接对应名字里的"荧光"——这不是 UI 标注，是果实自己的状态。

可调项：光晕半径、模糊度、透明度曲线、小果要不要做呼吸动画。 发霉那档我压了一层极弱的暗绿——如果觉得像"还活着"，可以干脆改成完全不发光。
