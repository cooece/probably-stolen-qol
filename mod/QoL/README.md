**交易结果弹窗**（参考工坊「声望增加显示 Reputation Pop」行为，自写）：拦截 `StoreReputation.OnItemTraded`（买卖结算声望的统一入口），prefix 记声望旧值、postfix 读新值求差得到**实际声望变化**（含难度/阵营/天赋全部倍率），金钱用成交价 + 买/卖方向判断（卖 +、买 -），最后用游戏自带的 `ReputationUIManager.Notify` 气泡弹出，如「声望 +0.6 · 现金 +163」。不画新 UI。

行为参考 DangpuPlus 0.3.148 的「真伪鉴定 / 一键鉴定」，实现自己重写，**没有搬运它的代码、没有画任何新面板/按钮/快捷键**：

- **真伪结论**：`真品` / `假货：{真实状态}（问题：防伪标、字母印刷…）` / `有隐藏缺陷：{真实状态}` / `水质虚标：标 x，实为 y`。判定只读游戏自己的 `ItemFeature`（`fakeCondition` / `realCondition` / `IsFeatureMatch()` / `IsRealFeatureCheaper()`）和水质档位标签。绿=真品、红=假货、橙=隐藏缺陷。
- **真实价值**：真假烟/邮票/注射器这类「变形」物品（`isTransformative`），真实价靠揭穿动作改 `unitValue`（假烟 100→50），用 `compareValue` 折扣率折算（只在未揭穿时）；其余物品按游戏同一套分段价格公式把「显示修正值」换成「真实修正值」重算。**先用显示修正值算一遍，对不上游戏显示价就整行不显示**（安全降级，绝不给错误数字）。真实价低于显示价标红（被高估），高于标绿（捡漏）。
- **估价物品**：估价客户放上台面的手、肋排、等离子燃料（`APPRAISAL_ITEM` 标签）显示「正确价值 N」，数据取自游戏 `AppraisalItemRegistry.getCorrectValue`（原版只在 devMode 显示，这里无条件揭示），方便精准出价。
- **估价自动鉴定**（参考 DangpuPlus 的 AppraisalAutofill，自写）：
  1. **自动填完美报价**：打开估价物品的检查面板时，报价框自动填「正确价值 × 105%」的完美报价（105% 是游戏完美档位上限），直接点确认即可。
  2. **自动批量提交**：估价客户放好物品、开场白一结束，就自动把台面上所有待估价物品依次按 105% 报价提交，全程不用按任何键。
  3. 估价单等纸张的自动丢弃已独立为「自动丢弃单据」功能（单开关，覆盖鉴定单 / 事件回执单 / 治安回执单 / 手写便签 / 探险日志）。
- **自动鉴定**：谈判窗口打开时每 0.5 秒用台面物品 ID 签名去重，顾客放上新物品才跑一次；对未揭穿且真实更差的特征调 `ExposeFeature(true, false)`，虚标水质额外走 `OnWaterLabelUpdated`，最后 `RefreshUI()`。只处理还不归玩家所有的物品。
- 非空水容器会显示一行真实水质（水质虚标属于真伪判定范围）。

> 注意：自动揭穿会改变游戏内物品的「已揭穿」状态——这正是参考模组「一键鉴定」的本来行为，关掉开关即停止。

## 开发者工具

只用游戏自带的 **F9 调试面板**，模组不再自建面板、不再有 F5 / F6 热键。

| 设置项 | 默认 | 作用 |
|---|---|---|
| 汉化调试面板（F9） | 开 | 把 F9 主面板、营销/剧情/模组子面板，以及物品生成器、顾客图鉴等调试窗口的按钮、分组标题、窗口标题、提示文字译成中文。关掉即还原英文原版 |
| 调试面板快捷键 | F10 | 除 F9 外额外一个可自定义的开关键，可选 无 / F5 / F6 / F7 / F8 / F10 / F11 / F12，改完立即生效 |

**实现**（`DebugPanelZh.cs`）：

- Harmony prefix 拦截 `CustomUIBuilder.AddButton / AddLabel / AddHeader / AddWarning / AddInput / AddToggle / AddDropdown` 与 `CustomUIManager.CreateWindow` 的文本参数，按字典精确替换。字典只放调试面板特有的英文，其它界面对不上就原样放行，不会误伤。
- 分组标题传的是 `"<b>Store</b>"` 这种带富文本标签的字符串，`Zh()` 会先剥掉 `<b></b>` 再查字典并包回去；带数字的动态说明（如 "76 of 276 customers…"）用正则/片段规则处理。
- 自定义键：设置里选 KeyCode 名，每帧检测 `Input.GetKeyDown`，按下时收起子页并 `CustomUIDebugPanel.Toggle()`。
- **不再有任何翻页按钮**（实测不好用，已移除），面板保持游戏原生结构；`OpenSubPanel` 本身会隐藏主窗口，所以主面板与子面板不会叠在一起。

> 游戏 F9 面板里「顾客」那一栏位于营销页，需要 `1dev.txt`；`dev.txt` 只开基础权限。两个文件都在游戏根目录，均为 0 字节标记文件，删除即关闭。物品 ID、顾客 ID 这类标识符**不翻译**（翻译了反而没法用）。

## 写提示框文字的坑（改代码前必读）

1. **不能用 `NextLine()` 换行**。它塞的是空文本切片，渲染时被跳过，换行失效 → 两行文字叠在一起。要用 `AddLine()`。
2. **不能出现半角 `<`**。提示框走 TMP 富文本，`<0.01%` 会被当成标签开头吞掉后续文字。用 `≤`。
3. **不能靠 TMP 自动折行**。提示框高度按行数算，折出来的半行不占高度会压在别的行上。
4. **存在型标签不能用 GetBool 判断**（`machinery`、`HYDROPONIC_MACHINE_TAG` 这类只记录有无的标签会误报 false），要用 `IsTag`；但反过来 `IsTag` 对另一批标签又会漏报——最稳的办法是照抄原版源码对每个标签的读法。
5. **`RichTextBuilder.Add(另一个builder)` 会用对方的挂起换行覆盖自己的**，合并前要先 `NextLine()` 塞一个显式换行切片。
